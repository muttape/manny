# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use the repository's **Security** tab to submit the report privately.

Include, when possible:

- the affected Manny version;
- a clear description of the vulnerability;
- reproduction steps or proof of concept;
- the expected security impact;
- relevant logs, screenshots, or files;
- any known mitigations.

Please avoid publicly disclosing the vulnerability before it has been reviewed.
